# ระบบจัดทำและพิมพ์เช็ค (Cheque Management & Printing System)

ระบบจัดทำและสั่งพิมพ์เช็คมาตรฐานสำหรับโรงพยาบาล หน่วยงานสาธารณสุข และองค์กรภาครัฐ รองรับการสั่งจ่ายเช็คธนาคารกรุงไทย (KTB), ธนาคารเพื่อการเกษตรและสหกรณ์การเกษตร (ธ.ก.ส. / BAAC) และธนาคารออมสิน (GSB) พร้อมระบบจัดเก็บประวัติการพิมพ์ย้อนหลัง และรองรับการทำงานข้ามปีงบประมาณได้อย่างสมบูรณ์

---

## 🏛️ สถาปัตยกรรมระบบ (System Architecture)

ระบบถูกออกแบบแยกส่วนระหว่าง **Backend** และ **Frontend** อย่างชัดเจน:

```
├── server/                      # [Backend Architecture]
│   ├── routes/
│   │   ├── cheques.ts           # RESTful API: /api/cheques (ค้นหา, สร้าง, แก้ไข, ยกเลิก)
│   │   ├── templates.ts         # RESTful API: /api/templates (พิกัดแม่แบบเช็คแต่ละธนาคาร)
│   │   ├── users.ts             # RESTful API: /api/users (การยืนยันตัวตน, จัดการสมาชิก)
│   │   └── logs.ts              # RESTful API: /api/logs (Append-Only Print & Audit Logs)
│   └── db/
│       └── memoryDb.ts          # Backend Datastore พร้อม Initial Seed Data
├── server.ts                    # Backend Server Entry Point (Express + Vite Middleware)
│
├── src/                         # [Frontend Architecture]
│   ├── components/              # ส่วนประกอบหน้าจอแสดงผล (UI Components)
│   │   ├── EasyChequeWriter.tsx # หน้าเขียนและสั่งพิมพ์เช็คด่วน
│   │   ├── ChequeHistoryView.tsx# ทะเบียนประวัติและรายงานการออกเช็คทั้งหมด
│   │   ├── ExecutiveSummaryView.tsx # แดชบอร์ดสรุปยอดผู้บริหาร
│   │   ├── SettingsView.tsx     # เครื่องมือตั้งค่าพิกัดแม่แบบพิมพ์ (มม.)
│   │   ├── ChequePrintModal.tsx # โมดอลพรีวิวและประมวลผล PDF เวกเตอร์ 300 DPI
│   │   ├── ChequeDetailModal.tsx# ป็อปอัปแสดงรายละเอียดเช็คและประวัติการพิมพ์ฉบับสมบูรณ์
│   │   ├── UserManagementModal.tsx # จัดการสมาชิกและสิทธิ์การใช้งาน
│   │   └── Navbar.tsx           # แถบเมนูนำทางหลัก (Responsive)
│   ├── services/
│   │   └── api.ts               # ตัวเชื่อมต่อ API ฝั่ง Client (พร้อม Fallback Storage)
│   ├── types/
│   │   └── index.ts             # โครงสร้าง Type Definitions ทั้งหมด
│   └── utils/
│       ├── dateUtils.ts         # การคำนวณปีงบประมาณไทย (1 ต.ค. - 30 ก.ย.) และวันเวลา พ.ศ.
│       ├── pdfGenerator.ts      # Engine เรนเดอร์ PDF เวกเตอร์ความละเอียดสูง
│       ├── printUtils.ts        # ยูทิลิตีระบบสั่งพิมพ์
│       ├── storage.ts           # Local Persistence & Seed Management
│       └── thaiBahtText.ts      # แปลงตัวเลขเป็นจำนวนเงินตัวอักษรภาษาไทย (บาทถ้วน)
```

## ✨ คุณสมบัติเด่นของระบบ (Key Features)

### 1. เขียนและสั่งพิมพ์เช็คด่วน (Fast Cheque Writer)
- รองรับการกรอกข้อมูลแบบขั้นตอนเดียว: วันที่, ปีงบประมาณ, เลขที่ฎีกา, เลขที่เช็ค, ชื่อผู้รับเงิน
- คำนวณยอดเงินและภาษีหัก ณ ที่จ่ายอัตโนมัติ (0%, 1%, 2%, 3%, 5%)
- แปลงจำนวนเงินสุทธิเป็นตัวอักษรภาษาไทย (บาทถ้วน) อัตโนมัติ โดยไม่ใส่เครื่องหมายแปลกปลอม
- ดึงข้อมูลจากประวัติเดิมที่เคยสั่งจ่ายเจ้านั้นในเดือนก่อนๆ มาออกเป็นเช็คฉบับใหม่รอบนี้ได้ทันที (ไม่ถือว่าพิมพ์ซ้ำ)

### 2. รองรับการทำงานข้ามปีงบประมาณ (Fiscal Year Management)
- ระบบคำนวณรอบปีงบประมาณภาครัฐไทย (1 ตุลาคม - 30 กันยายน) ให้อัตโนมัติ
- ผู้ใช้สามารถเลือกปีงบประมาณในหน้าเขียนเช็คได้อย่างอิสระ (เช่น 2567, 2568, 2569, 2570) รองรับกรณีเงินกันไว้เบิกเหลื่อมปี
- ตัวกรองปีงบประมาณในทะเบียนประวัติเช็คและแดชบอร์ดผู้บริหาร
- ช่องค้นหาสามารถพิมพ์ปีงบประมาณ เช่น `2569`, `2570` เพื่อค้นหาข้อมูลได้ทันที

### 3. ทะเบียนประวัติเช็ค & บันทึกการพิมพ์ (Cheque History & Append-Only Audit Trail)
- แสดงประวัติว่า **ใครเป็นผู้พิมพ์**, **จำนวนครั้งที่พิมพ์** และ **วันเวลาที่สั่งพิมพ์ล่าสุด**
- เมื่อมีการสั่งพิมพ์ซ้ำ (Reprint) ระบบจะบังคับให้ระบุเหตุผล (เช่น เช็คพิมพ์ผิด, กระดาษติด) และบันทึกลง Audit Trail โดยไม่มีการลบประวัติเก่า
- ส่งออกข้อมูลเป็นไฟล์ Excel / CSV พร้อมรองรับภาษาไทย UTF-8 BOM

### 4. แดชบอร์ดสรุปผู้บริหาร (Executive Dashboard)
- รายงานสรุปยอดเบิกจ่าย ยอดเงินตามธนาคาร และ 5 อันดับผู้รับเงินสูงสุด
- กรองสรุปยอดตามปีงบประมาณ หรือตามช่วงเวลา (ทั้งหมด, เดือนนี้, วันนี้)

### 5. แม่แบบและระบบปรับพิกัดเครื่องพิมพ์ละเอียดระดับมิลลิเมตร (Calibration)
- รองรับขนาดเช็คมาตรฐาน 3 ธนาคารหลัก:
  - **KTB (ธนาคารกรุงไทย)**: 241 × 90 มม.
  - **BAAC (ธ.ก.ส.)**: 235 × 90 มม.
  - **GSB (ธนาคารออมสิน)**: 239 × 90 มม.
- มีระบบพิมพ์แผ่นทดสอบเทียบพิกัดบนกระดาษ A4 เพื่อเช็คตำแหน่งก่อนพิมพ์ลงกระดาษเช็คจริง

### 6. รองรับการใช้งานบนมือถือและแท็บเล็ต (Mobile Responsive)
- ออกแบบให้ใช้งานสะดวกผ่านสมาร์ทโฟนทุกขนาดหน้าจอ
- การ์ดแสดงผลข้อมูลเช็คสำหรับมือถือโดยเฉพาะ
- ปุ่มคำสั่งขนาดใหญ่ แตะสัมผัสง่าย ไม่ล้นจอ

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend**: React 19, TypeScript, Tailwind CSS 4, Lucide React, Motion
- **Backend**: Node.js, Express 4, tsx
- **Build Tool**: Vite 8
- **PDF & Canvas**: jsPDF, Canvas 2D Vector Rendering
